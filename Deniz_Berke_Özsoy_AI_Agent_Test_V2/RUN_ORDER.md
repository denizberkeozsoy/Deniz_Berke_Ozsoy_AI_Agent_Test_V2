# Run Order

1. Open `multi_agent_data_analysis_assistant_colab_enhanced.ipynb` in Google Colab.
2. Ensure the Drive folder exists: `/content/drive/MyDrive/multi_agent_data_analysis_assistant_colab_package`.
3. Put `vehicles.xlsx`, `holidays.xlsx`, and `weather.xlsx` in that Drive folder or upload them into Colab.
4. Run cells from top to bottom.
5. Check `outputs/charts`, `outputs/reports`, and `artifact_manifest.json` under the Drive folder.
